# Perfume E-Commerce Website

## About the Project

The **Perfume E-Commerce Website** is a static e-commerce website designed for showcasing perfume products in a simple and user-friendly interface. The website includes different sections for browsing perfume categories, viewing account details, checking orders, and making payments.

## Technologies Used

* HTML
* CSS

## Features

* Home page
* Perfume categories
* Product display
* Account page
* Orders page
* Payment page
* User-friendly navigation
* Attractive perfume product images

## Pages

* **Home** – Displays the main perfume products and website content.
* **Categories** – Displays perfumes based on different categories.
* **Account** – Provides the user account section.
* **Orders** – Displays order-related information.
* **Payment** – Provides the payment section.
